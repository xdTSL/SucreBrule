# Sucre Brulé – website (GitHub Pages)

Upload de INHOUD van deze map naar de root van een GitHub-repo (index.html moet bovenaan staan),
en zet daarna Settings → Pages → Deploy from branch → main → / (root) aan.

Na het live gaan: vervang in index.html `https://VUL-IN.example/` (og:url en og:image)
door de echte URL, bv. https://<gebruikersnaam>.github.io/<repo>/
